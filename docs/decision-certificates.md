# 0.2.0 证书 API 移除说明

0.1.x 曾允许从任意两个 EmailView 生成逐位置来源证书，并离线验证内部一致性。这与来源映射、重放和见证工具存在明显机制交集；它也不携带完整邮件字段或认证的服务器响应。

0.2.0 删除 certificate.mbt 和全部证书公共类型、构造器、别名及 verifier，不再交付证书、来源槽或通用审计层。删除前源码和测试留在本次本地基线归档及 Git 历史中。

调用方在 Commit 后使用 `committed_emails(view)` 取得按查询顺序排列的可展示对象。该函数检查当前 Ready 条件并复制集合，不签名、不证明远端真实性，也不替代服务器读响应。同步过程继续使用 Checkpoint 保存未完成工作，它不是证明文件。

这是有意的 API 不兼容修改。本地版本 0.2.0 尚未发布；安装 0.1.1 仍得到旧 API。旧的 4,225 种证书转移测试是历史证据，不列为当前功能或本轮测试通过项。
