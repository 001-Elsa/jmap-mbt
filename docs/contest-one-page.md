# MoonJMAP 本地 0.2.0 概要

为指定邮箱最新/未读邮件维护一个有界连续窗口。只在两条 JMAP 状态链完成、邮件字段齐全且仍匹配视图时提供 Ready 记录；当服务端声明不能计算 query changes 时，自动退回完整查询，不伪造增量结果。

本地序列重建和独立来源证书已移除。变化只使受影响后缀失效，再在同 queryState 下向服务器读取；对象更新使旧字段立即失效；`committed_emails` 按查询顺序返回分离的记录。

协议组合、前缀失效和版本一致读取已有先例。每项改动后另做当前 Mooncakes 全量静态比较，不作零相似和赛事接受保证。0.2.0 尚未发布或推送；旧发布包为 0.1.1。开发历史与来源边界见 repository-import.md 和 source-provenance.md。
