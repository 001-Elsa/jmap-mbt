# MoonJMAP：固定邮箱窗口的保守同步

当前本地未发布版本 0.2.0 接收 JMAP 响应，维护指定邮箱最新或未读邮件的前 N 条，输出下一条请求、刷新要求或 Ready 的可展示记录。

本次实质修改包括：完整对象仍须满足邮箱/未读条件；窗口内属性更新立即删除旧字段；`canCalculateChanges=false` 时自动退回完整查询；移除本地 survivors/排名归并，改为保留确定开头并按同 queryState 向服务器重读后缀；删除独立位置证书层；展示出口只允许当前 Ready 数据。

代价是更多查询与可能的对象重取。协议双状态组合、版本一致读取、前缀失效、恢复与预算均有先例，不主张基础算法独创。与邮件协议、集合对账、CDC、JSON patch、VCDIFF 和见证项目的共有机制及残余风险需要披露。

每项修改后均固定当前官方 Mooncakes 目录、核验发布归档，并对当前核心做全量静态比较；候选核读和语义范围单独记录。它不证明零相似、独立创作或赛事通过。
