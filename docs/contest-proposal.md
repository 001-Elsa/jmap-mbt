# MoonJMAP：固定邮箱窗口的保守同步

当前本地未发布版本 0.2.0 接收 JMAP 响应，维护指定邮箱最新或未读邮件的前 N 条，输出下一条请求、刷新要求或 Ready 的可展示记录。

## 本期只交付三件事

1. **JMAP 有界邮件视图内核。** 在 MoonBit 中维护 `Latest(inbox)` / `Unread(inbox)` 的有界前缀，协调 Email state 与 queryState；窗口内对象变化立即失效，只有服务器确认的新后缀和完整对象条件满足时才发布 Ready。
2. **可运行的四方法 wire 适配和能力降级。** 对 `Email/query`、`Email/get`、`Email/changes`、`Email/queryChanges` 生成带账号、查询、排序、ticket 和 `calculateTotal` 的 typed 请求；服务端声明 `canCalculateChanges=false` 时退回完整查询，不伪造增量结果。
3. **可复现的边界测试与真实服务互操作记录。** 保留 MoonBit/Python 边界测试、固定输入对拍和本机 Stalwart 变更记录；记录包含 5 封邮件、已读突变、四方法响应摘要、前缀截断、新 queryState 后缀补位和最终成员资格断言。

代价是更多查询与可能的对象重取。协议双状态组合、版本一致读取、前缀失效、恢复与预算均有先例，不主张基础算法独创。四方法 wire、边界测试和实服记录服务于上述三件交付，不扩展为通用 replay、通用证书、通用 trace、通用 CDC、邮件客户端或更多协议支持。

每项修改后均固定当前官方 Mooncakes 目录、核验发布归档，并对当前核心做全量静态比较；候选核读和语义范围单独记录。它不证明零相似、独立创作或赛事通过。
